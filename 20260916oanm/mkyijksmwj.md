# 医院开展中美远程会诊新模式 足不出户享受美国优质医疗

> 更新时间：2026-09-16 (UTC+8)

10月16日上午，我院黄山路肿瘤科主任汤雷、核医学科主任冒斌、肿瘤科副主任李孝鹏等相关专家在我院远程会诊中心与远在美国专家“隔空”对话，共同为一例腹壁肿瘤患者商讨治疗方案。

 

王先生现年60岁，去年因为右上腹部包块接受手术治疗，术后病理显示为中分化腺癌，侵犯骨骼肌，术后未进行放化疗治疗。今年1月腹部包块复发，大小约6cm，质地硬，再次接受手术治疗，术后病理显示“浸润性/转移性腺癌”，但胃肠镜检查、PET/CT、MRI等检查均未发现肿瘤原发病灶。今年8月，在早期手术部位发现有新发病灶侵犯骨影肌，但无法手术切除。此次慕名前往我院医院远程会诊中心，接受中美远程会诊。

 

参加本次会诊的美国医生Sidharth Anand博士为加利福尼亚大学洛杉矶分校圣莫妮卡医学中心执业的医学肿瘤学家和血液学家，在消化系实体肿瘤的个性化诊治方面造诣深厚。我院远程医疗中心提前将王先生病例检查资料发给美国专家，视频会诊中，美国专家进一步询问了王先生的近况，经过1个多小时的视频沟通，Sidharth Anand博士与我院专家达成了诸多共识，建议进一步完善Cancer type ID检测，明确肿瘤原发病灶，检测肿瘤免疫表达情况，并就后续检查和治疗方案给出了重要的诊疗意见。

中美远程会诊是我院与国际前沿医疗水平的一次接轨。通过远程会诊，在院内专家与国外顶尖医学专家的不断交流中，可以不断优化患者的诊疗方案，最大程度改善治疗效果，以本次会诊为例，患者无需花费巨额的费用、时间和精力远渡重洋，等待一个未知的美国诊疗方案。现在只需通过中美远程会诊，在国内专业医疗机构的指导下，通过中美双方专业医生的共同探讨，就能得到较专业、可靠和前沿的诊疗方案。

 

随着互联网技术的发展，互联网与医疗健康深度融合，发展远程医疗服务成为优化医疗资源配置和解决群众看病就医难问题的重要手段。安徽省第二人民医院远程会诊中心自启动以来开展了十余次中美远程会诊，让更多的患者享受到了美国医学专家的诊疗服务。中美远程会诊让临床实践和医疗服务突破国界，满足了疑难重症疾病患者对国际高端医疗的需求，为提高我省临床诊疗水平发挥了重要作用。
